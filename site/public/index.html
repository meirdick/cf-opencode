Run OpenCode sessions remotely, in your own Cloudflare account.

cf-opencode puts OpenCode in Linux workspaces on Cloudflare Containers. Attach from your laptop, or hand off a task and close it. The session keeps running, and your code stays in your account.

npx cf-opencode init
Read the quickstart View on GitHub

Open source under Apache-2.0. Runs in your own Cloudflare account.

The problem

A local agent stops with your laptop
It stops when you close the laptop or lose Wi-Fi. It also runs shell commands and sudo installs on your real machine.
A hosted agent keeps your code elsewhere
It stays awake, but your private repositories, environment state and credentials are on someone else's servers.
cf-opencode runs in your account
Each workspace is its own Linux container in your Cloudflare account. There is no hosted service between you and your workspaces.

How it works

  1. Deploy once to your account

    Setup checks your machine, connects GitHub one time, and deploys one Worker and the workspace image into your Cloudflare account.

  2. Work live or hand off a task

    Attach your local OpenCode, or start a task in the background. The agent gets a terminal in tmux, SSH, sudo apt-get, web search and a browser. cf-opencode preview 3000 opens the agent's dev server at localhost on your machine.

  3. Pause when idle, wake with your session

    After 20 idle minutes by default, the workspace saves its disk to a snapshot and pauses. Your next connect restores your files, installed tools and OpenCode session.

One workspace across a workday

The workspace is awake while you or the agent work. It pauses when the work stops.

  1. 09:00Connect and give the agent a task
  2. 09:40Close your laptop. The agent keeps working
  3. 11:30Task finishes. 20 idle minutes pass
  4. 11:50Workspace pauses. The disk is saved as a snapshot
  5. 15:10Reconnect. It wakes with your session

The times are an illustration. The 20-minute idle pause is the default.

What Cloudflare bills

Everything is billed to your own Cloudflare account. Cloudflare bills compute while a container runs. That includes the idle minutes before a pause and the warm period after it. Model usage and browser hours are billed too.

Questions

Where do my code and snapshots live?
In your Cloudflare account. The Worker, the containers and the disk snapshots are there. No hosted service sits between you and your data.
Can the agent leak my GitHub token?
Setup connects GitHub one time, so workspaces can clone, push and run gh. Your GitHub token stays in the Worker and never enters a workspace container.
Which models work, and do I need an API key?
You need no API key. The default model is cloudflare-workers-ai/@cf/zai-org/glm-5.3, and any Workers AI @cf model works. Anthropic, OpenAI, Google and others run through AI Gateway on credits. To use your own keys, set ANTHROPIC_API_KEY or OPENAI_API_KEY as Worker secrets.
What size is a workspace, and how many can run?
By default a workspace has 2 vCPU, 6 GiB of memory and a 20 GB disk. The instance setting also accepts lite and standard-1 to standard-4. Up to 10 workspaces run at once by default. Set maxRunning from 1 to 100. Limits and costs

Install and use

What you need

  • Node 22 or newer
  • Docker, with the buildx plugin
  • A Cloudflare account on the Workers Paid plan
  • OpenCode 2 on your machine

  1. Install into your account

    npx cf-opencode init

    Checks your machine, then deploys one Worker and the workspace image into your Cloudflare account.

  2. Connect from a git checkout

    npx cf-opencode connect

    Starts a workspace, clones the repository there, and opens your local OpenCode against it.

  3. Leave and reconnect later

    npx cf-opencode connect --continue

    The agent works with no client attached. When you return, this opens the last session in the workspace.

  4. Hand off a background task

    cf-opencode run "<task>"
cf-opencode tasks

    run starts an agent in the workspace and returns at once. tasks shows the summary, the branch and the pull request.
